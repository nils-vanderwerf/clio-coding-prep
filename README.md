# clio-coding-prep

A Ruby practice repo covering core programming topics with exercises and RSpec specs.

## Contents

### Topics

| Folder | Focus |
|---|---|
| `01_arrays_hashes/` | map, select, each_with_object, hash building, frequency counting |
| `02_classes_oop/` | initialize, instance methods, attr_accessor, encapsulation |
| `03_rspec_testing/` | describe, context, let, expect, matchers |
| `04_string_manipulation/` | split, chars, reverse, caesar cipher, run-length encoding |
| `05_recursion_algorithms/` | base case, recursive case, practical problems |
| `06_mock_interview/` | timed practice problems |

### Reference Files

- `CLAUDE.md` — core patterns reference card (hash pattern, Big 5 array methods, RSpec matchers)
- `HINTS.md` — hints for every exercise, no solutions

## Running Tests

```bash
bundle exec rspec mnt/user-data/outputs/clio-coding-prep/03_rspec_testing/exercises_spec.rb
bundle exec rspec mnt/user-data/outputs/clio-coding-prep/04_string_manipulation/exercises_spec.rb
```

bundle install
